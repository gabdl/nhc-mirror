# nhc-mirror

Mirror of the NOAA/NHC graphical Tropical Weather Outlook partials
(`two_atl_2dx.html`, `two_atl_7dx.html`), refreshed every 30 minutes by a
scheduled GitHub Action.

CARICOOS (caricoos.org) uses this as a fallback source for its
[hurricane season page](https://www.caricoos.org/hurricane-season) while
NOAA's CDN blocks our server IPs. All mirrored content is public NOAA
data; source: https://www.nhc.noaa.gov/xgtwo/
